# Developer Changelog: devLog

A Next.js application that automatically generates concise daily stand-up summaries from your GitHub commits using local LLMs. 

## Overview
devLog helps you remember what you worked on yesterday. Sign in with GitHub, pick a repository and a date range, and devLog syncs your commits and sends them to a local Ollama model to produce a readable summary.

## Features

- **GitHub OAuth**: Sign in with GitHub and browse your repositories.
- **Commit syncing**: Choose a repository and a range (last 24 hours, last 7 days, or custom dates). Commits are stored in a local SQLite database.
- **Webhooks**: Point a GitHub webhook at `/api/webhooks/github` to sync commits on every push. Incoming requests are verified against GitHub's signature header (`X-Hub-Signature-256`) before anything is processed.
- **Local AI summaries**: Summaries are generated by a model running on your machine through Ollama (default: `llama3.2`), so your code details stay local.
- **Privacy-minded dashboard**: Built for local setups, with views that keep project internals out of sight during screen-shares.

## Roadmap

## Prerequisites

- Node.js 18 or higher
- A GitHub OAuth app (for the client ID and secret)
- [Ollama](https://ollama.com) running locally with a model pulled, e.g. `ollama pull llama3.2`

## Getting Started

1. Clone the repository and install dependencies:
```bash
git clone https://github.com/Tee-chan/devLog.git
cd devLog
npm install
```

2. Copy the example environment file and fill in the values:
```bash
cp .env.example .env.local
```

| Variable | Description |
|----------|-------------|
| `GITHUB_ID` | Client ID of your GitHub OAuth app |
| `GITHUB_SECRET` | Client secret of your GitHub OAuth app |
| `NEXTAUTH_SECRET` | Random string used to sign sessions (generate with `openssl rand -base64 32`) |
| `NEXTAUTH_URL` | `http://localhost:3000` in development |
| `GITHUB_WEBHOOK_SECRET` | Shared secret used to verify webhook signatures |

When creating the GitHub OAuth app, set the callback URL to:
`http://localhost:3000/api/auth/callback/github`

3. Generate the Prisma client and create the database:
```bash
npx prisma generate
npx prisma db push
```

4. Start the development server:
```bash
npm run dev
```

5. Open http://localhost:3000 in your browser.

## Configuration

Open the Settings page to set your Ollama endpoint and model. By default, devLog connects to `http://localhost:11434` with `llama3.2`.

## Webhook Setup

1. In your GitHub repository, go to Settings → Webhooks → Add webhook.
2. Payload URL: `https://<your-public-url>/api/webhooks/github` 
3. Content type: `application/json`.
4. Secret: the same value as `GITHUB_WEBHOOK_SECRET` in your `.env.local`.
5. Events: select "Just the push event".

## Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS
- **Database:** SQLite with Prisma ORM
- **Auth:** NextAuth.js (GitHub provider)
- **Integrations:** GitHub API, Ollama API
